# Contribuindo / Contributing

Obrigado pelo interesse em contribuir com o Teleprompter!

1. Abra uma issue para descrever um problema ou sugerir uma funcionalidade.
2. Faça um fork do repositório e crie uma branch para sua alteração.
3. Mantenha o projeto simples, sem novas dependências quando não forem necessárias.
4. Teste a alteração em navegadores desktop e mobile, sempre que possível.
5. Envie um pull request com um resumo do que mudou e como testar.

Ao contribuir, você concorda que sua contribuição será disponibilizada sob a licença MIT do projeto.

---

Thanks for contributing! Please open an issue for bugs or feature requests, create a dedicated branch, test your changes, and submit a pull request with a clear description. Contributions are made under the project's MIT license.
