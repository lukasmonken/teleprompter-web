# Teleprompter Web v2.1.0 — Initial Open Source Release

Primeira versão pública do **Teleprompter Web**, uma aplicação gratuita e responsiva para leitura de roteiros durante gravações, apresentações e produção de conteúdo.

**Teste online:** https://lukasmonken.github.io/teleprompter-web/

## Destaques

- Rolagem automática com 10 níveis de velocidade.
- Modo espelhado para acessórios de teleprompter.
- Ajustes de tipografia, alinhamento e largura de texto.
- Contagem regressiva, guia de foco e acompanhamento de progresso.
- Gestos para pausar, retomar e reposicionar o texto.
- Controles flutuantes, atalhos de teclado e bloqueio de controles.
- Importação/exportação de arquivos `.txt` e salvamento automático no navegador.
- Suporte opcional a tela cheia e manutenção da tela ativa, conforme compatibilidade do navegador.

## Sobre o projeto

Desenvolvido com **HTML, CSS e JavaScript puro**, sem dependências, conta ou backend. Os roteiros são armazenados localmente no navegador e não são sincronizados entre dispositivos.

**Código-fonte:** https://github.com/lukasmonken/teleprompter-web

**Licença:** MIT.

### English

First public open-source release of **Teleprompter Web**, a free and responsive browser teleprompter made with vanilla HTML, CSS and JavaScript. It includes adjustable auto-scrolling, mirror mode, focus guide, text customization, touch controls, text file import/export and browser-local autosave. The interface is currently in Portuguese.

**Live demo:** https://lukasmonken.github.io/teleprompter-web/
