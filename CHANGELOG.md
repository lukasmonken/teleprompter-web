# Changelog

As mudanças relevantes do Teleprompter Web serão registradas neste arquivo.

O projeto utiliza versões no formato `MAJOR.MINOR.PATCH`.

## [2.1.0] — 2026-10-29

Primeira versão disponibilizada publicamente como projeto open source.

### Funcionalidades disponíveis

- Rolagem automática com 10 níveis de velocidade.
- Personalização do tamanho, espaçamento, largura e alinhamento do texto.
- Modo espelhado e guia de foco central.
- Contagem regressiva antes da leitura.
- Controles flutuantes, gestos de toque e atalhos de teclado.
- Barra de progresso, opção de bloquear controles e retomada da posição.
- Importação e exportação de roteiros `.txt`.
- Salvamento local automático com `localStorage`.
- Tela cheia e opção de impedir suspensão quando suportadas pelo navegador.

### Documentação e distribuição

- Código publicado sob a licença MIT.
- README bilíngue e instruções de contribuição.
- Aplicação estática disponível pelo GitHub Pages.

> Observação: este registro descreve a versão do código. A publicação de uma *GitHub Release* e da tag `v2.1.0` é uma etapa separada.
